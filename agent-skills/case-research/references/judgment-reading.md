# 裁判阅读与身份核验

## 案例卡字段

- 来源：实际附件/知识库条目、材料标题、页码或段落、现有链接。
- 身份：法院、案号、日期、文书类型、审级/程序、案由。缺失字段标“材料未载明”。
- 状态：材料是否载明生效、上诉、再审、撤销或改判；未提供后续文书时不得认定裁判结果未改变。
- 事实：分别列当事人主张、证据记载、法院认定，保留对争点有决定作用的事实。
- 规则与理由：法院实际使用的规则、事实到结论的推理，以及不予采纳的意见。
- 结论：请求如何处理、是否只解决程序问题、哪些问题未作判断。

## 阅读顺序与易错点

1. 先确认文书类型与处理事项，再读请求和抗辩、法院认定、理由及裁判结果。
2. 案号不能证明内容、效力或真实性。材料中写有“典型”也不自动等于指导性案例。
3. 裁判节选或新闻稿只能支持其实际陈述，不能补齐完整判决或全部证据情况。
4. 区分裁判理由与当事人单方论证；引用对方主张时明确主体，不能写成法院观点。
5. 涉及赔偿额、期限或比例时保留基数、期间和计算范围；与本案事实不同的数额不能直接套用。
6. 没有精确原文时使用转述；直接引文保留限定条件与材料定位。

无法确认某案例真实性或后续状态时，交付为“待核实参考”，不要假装完成官方数据库核验。
