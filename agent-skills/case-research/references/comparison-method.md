# 类案比较方法

## 先比较能够改变结论的因素

| 比较维度 | 提问 |
| --- | --- |
| 争点与请求 | 两案是否解决同一个问题？请求与抗辩是否相同？ |
| 权利基础 | 权利类型、保护对象、权利状态及主张范围是否可比？ |
| 关键行为 | 行为方式、场景、对象、时间与地域有何差别？ |
| 证据与证明责任 | 关键事实是否被证明？举证条件或证据采信为何不同？ |
| 规则及版本 | 使用的规则、版本与适用前提是否一致？ |
| 程序与结论 | 是否均为实体处理？是否终审、生效或仅为程序裁定？ |

对每个案例写一句“可比的关键点”和一句“可能导致不同结论的差异”，不因法院层级高就跳过事实比较。

结果相反时，先检查事实认定、证据、请求范围、规范版本和程序背景，再判断是否可能存在观点分歧。资料不足时只报告分歧及需补充的文书，不能断言一方已被推翻。

对本案建议应当能够对应具体缺口，例如补充权利状态材料、厘清某个行为时间或索取完整裁判文书；不要从类案数量、裁判金额或未经验证的评分推出胜诉率。

输出检索方案时使用公共法律概念和去标识化事实，列出建议关键词、筛选项及待核验字段，不把未公开技术或客户名称包装成公共检索词。
