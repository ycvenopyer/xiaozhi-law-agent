# 政策状态与影响分析

先确认材料描述的阶段，再讨论业务影响：

| 阶段 | 适合的表述 | 必须检查 |
| --- | --- | --- |
| 提议、研究或媒体预测 | 可能方向、报道中的说法 | 是否存在可读的原始材料 |
| 征求意见 | 拟议规则及可能影响 | 意见期限是否载明，不能写成已生效义务 |
| 正式发布但尚未施行 | 已发布、待施行的变化 | 生效日期、过渡安排与适用对象 |
| 已施行的文件 | 基于提供文件的规则摘要 | 版本、适用范围及例外，当前效力仍需核验 |
| 个案或典型案例发布 | 对该案例的解释和参考 | 文书完整性、审级/效力、参考价值，不能泛化 |

影响分析拆成“材料明确变化—可能影响的业务环节—适用条件—可考虑的核验或准备动作”。例如建议核对某项申请流程，不等于断言所有客户都必须立即变更。

缺少旧规则时不能声称已经逐项完成新旧对照。涉及某企业内部案件时，公共简报仅保留公开材料支持的事实；内部客户名单、技术方案和未公开申请内容不因写简报而成为可公开信息。

事件本身、来源观点、分析推断分别标注；影响程度不使用无依据的量化评分，也不把资讯整理扩展为投资或案件结果预测。
