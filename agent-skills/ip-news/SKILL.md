# 知产资讯与政策简报

## 适用条件与开始要求

用于整理知识产权新闻、政策公告、裁判发布和行业动态，制作摘要、专题或多来源对比。至少有一份可读正文或实际可读的附件才开始事件总结；只有标题时只概述标题所表达的内容，不能扩写事件细节。

先识别目标读者、时间范围、关注主题和期望篇幅。没有这些偏好也可以先按用户提供材料生成短简报，不要求填写不影响结果的表单。只有网址或要求“今日最新”却没有正文时，明确当前无法抓取网页，请用户提供原文，不能生成虚构快讯。

## 工作流程

1. 建立材料清单，记录来源、发布日期、事件发生日、正文范围及已有链接。按 [资讯核验与分类](references/editorial-checklist.md) 区分原始公告、转载、评论和未经核实的说法。
2. 提取“发生了什么、谁在何时做了什么、材料明确了哪些变化”，不得把作者推测写成事件事实。
3. 合并同一事件的重复报道；多来源相互矛盾时保留差异并列待核实项，不擅自选择最吸引人的版本。
4. 涉及政策、规范或程序变化时，读取 [政策状态与影响分析](references/policy-impact.md)，区分发布、征求意见、通过、施行等不同阶段。
5. 按 [知产简报模板](assets/ip-brief.md) 输出事实摘要、来源与日期、业务影响和后续关注。用户仅需摘要时缩短影响部分，不强行给出行动建议。
6. 检查标题、时间范围及每项影响判断是否被材料支持。分析推断使用条件性表达，不把旧材料称为今日新闻。

## 交付与完成条件

每项资讯均可回到所给材料，发布日和事件日不混用；事实、评价及模型分析已区分；重复和冲突已处理；简报说明覆盖范围和缺失来源。没有可靠材料时完成的是补充材料请求，而非“零条也编几条”的新闻报告。

## 信息边界

本技能没有联网抓取或实时监控能力，不能声称已查遍新闻来源。客户卷宗、未公开技术及身份信息不应被挪用为公开简报内容；涉及私有材料时明确这是内部分析稿，必要时用去标识化表述。不能把征求意见稿、新闻解读或个案报道当作已生效的普遍规则。
