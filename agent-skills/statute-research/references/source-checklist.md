# 来源与引用规则

## 为每项依据建立记录

记录法律或文件名称、条号、制定机关、版本或修订日期、施行日期、资料位置、来源链接、支持的具体命题。材料未记载的字段写“材料未载明”，不得从常识补成确定事实。链接只能沿用已提供且确与该材料对应的链接。

## 区分支持程度

| 状态 | 可输出内容 | 不能作出的推断 |
| --- | --- | --- |
| 已提供完整原文及版本信息 | 与原文核对后的引文、条号、要件 | 未实际查询前不能宣称“当前仍有效” |
| 只有节选或汇编摘要 | 标明节选范围，概述资料记载的规则 | 不能补齐缺失段落或将摘要加引号当原文 |
| 只有裁判对法条的引用 | 说明该裁判材料如何使用该规则 | 不能据此认定法条全文、版本或普遍效力 |
| 只有用户陈述或模型记忆 | 给出核验方向、一般性解释并标明待核实 | 不能制造检索结果、文号或来源页 |

“材料记载某规则”与“该规则可适用于本案”是两个独立判断，均需说明理由。材料之间不一致时并列展示出处和差异，不用多数票决定正确版本。

## 引用检查

- 原文逐字引用须与所给文字一致，省略时标示范围；概述使用“要旨”而非冒充全文。
- 引用定位优先使用附件页码、标题、章节、条号或已有段落号；没有页码不能杜撰。
- 区分法律效力、解释参考、内部资料和检索线索，不把学术观点写成强制性规则。
- 待补充的来源可列国家法律法规数据库、全国人大、最高人民法院、国家知识产权局等官方核验渠道的名称；没有实际来源 URL 时不猜测文章地址。
- 输出前逐项核对：该来源是否确实支持紧邻的结论，是否遗漏限定条件或例外。
