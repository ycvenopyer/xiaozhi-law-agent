# 版本、时间与规则适用

当问题涉及旧法、新法、持续行为、不同地区或多个相互影响的规范时使用。

1. **分别建立时间线。** 记录被诉行为、权利取得、合同订立及履行、起诉等材料已载明的时间；另列规范公布、施行、修改、废止时间。缺失日期不猜测。
2. **明确需要解决的时间问题。** 实体规则、程序规则、期限起算、过渡安排分别检查。不能仅因为文件日期较新就认定应适用新规则。
3. **查找过渡条款或专门说明。** 仅根据现有材料分析；没有提供时标注“需补充过渡规定及效力信息”。不自行设定溯及既往规则。
4. **区分持续行为和多个行为。** 材料显示行为跨越规则变动时间时，分别列出各段事实、可能适用的规则与待核实条件，不把起诉日替代全部行为日期。
5. **识别冲突而非替用户补事实。** 对特别规定、一般规定、不同效力层级或不同法域，说明各自调整对象与适用前提。没有足够依据时保留多个分析分支。

可用输出：“若行为发生于【时间范围】，需核对【版本/过渡规定】；目前附件仅有【版本】，因此以下为基于该材料的条件性分析。”这不是任何具体案件的新旧法结论。
