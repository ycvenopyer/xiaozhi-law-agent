# 分类型条款检查

本文件是起草与审核的提问框架，不是现行法律条文或统一必备条款清单。只使用任务涉及的类型；需要具体效力判断时核验适用法域和最新规则。

## 技术开发

区分委托、合作和其他安排；识别背景知识产权、研发成果、改进成果、源代码/设计文件等交付物。明确研发范围、里程碑、验收标准与方法、缺陷修复、失败风险、费用支付、成果权属、使用及申请权、保密和对第三方材料的许可条件。不能把未成功研发直接等同于违约，需结合约定和事实分析。

## 知识产权许可

识别许可方的处分权限及其材料依据；列明权利标的、地域、期限、用途、许可类型、转许可、关联主体使用、质量控制、标识、改进成果、费用及核算、维权分工、第三方主张、终止后处理。独占、排他、普通等词语应有明确权利边界，不能只用名称代替条款。

## 知识产权转让

分别确认专利、商标、著作权或其他权益的标的及范围；核对共有、许可、质押、诉讼等负担是否有材料支持；衔接价款、权利交割、材料移交及必要手续。区分合同约束、权利变动、登记和履行义务，不能笼统认定所有类型都以登记生效。

## 保密与不披露

界定披露目的、信息范围及识别方式、保密例外、允许接触人员、按需使用、强制披露处理、保护措施、复制与反向工程限制、返还销毁及合法保留、期限与终止后义务。避免不必要地把完整秘密技术复制进协议。违约、举证及救济须与交易相称，不以夸大罚则替代可执行义务。

## 竞业限制

识别合同关系、适用人员、保护利益、限制活动及地域、期限、补偿、报告/核验、解除和违约安排。不要假定任何人员、任何范围的限制均有效；法律上限和必要条件根据适用规则核验，不凭模板填入固定期限。注意与保密义务、一般忠实义务的边界。
