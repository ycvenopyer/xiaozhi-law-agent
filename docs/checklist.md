# Agent 赛题功能检查清单

## 1.赛题

知识产权保护赛题：面向知识产权检索比对、侵权识别、知识产权合规提示、知识产权文书辅助生成等知识产权业务场景AI智能体。

## 2.作品形式

- 作品形态与技术要求作品须为可运行、可演示的法律AI智能体应用方案，具备清晰交互逻辑，能够完整演示核心业务功能，不限于网页、小程序、对话框等形式。

- Demo结构与功能说明须说明作品主题、功能模块、技术路线与创新点。提供Demo结构说明，包括：系统架构（入口、能力、数据、技术、输出各层）、核心运行流程（输入—处理—输出）、技术选型（所用模型、框架与数据来源），同时须清晰说明法律实务应用场景。鼓励附上可运行代码或演示链接，便于评委进行真实场景验证。

## 3.原创要求

参赛作品须围绕法律相关主题设计，坚持正确政治方向和学术导向，须为参赛选手原创开发，严禁抄袭、剽窃、窜改他人成果，不得直接套用现成商业化产品。允许使用各类开源框架、商用大模型开展二次开发，所有AI工具使用情况须在技术文档内完整注明。参赛作品知识产权归参赛选手所有，提交作品即视为授权主办方、承办方拥有非商业性的展示权、宣传权、推广使用权。作品若引用第三方开源组件、数据集，应当标注来源，规避知识产权侵权风险。

## 4.合规性和伦理要求

智能体输出内容法律适用应当严谨准确，不得输出错误法律意见；严格落实数据安全、个人信息保护相关法律法规，严禁非法采集、泄露个人隐私；AI生成内容按照国家相关规定予以标注；不得存在算法歧视，符合人工智能伦理规范。若作品存在重大法律错误、隐私泄露风险、伦理缺陷等问题，将直接取消参赛资格。

## 5.材料要求

参赛选手在除了报名表之外的其他参赛材料中均不得以任何形式透露个人身份信息，参赛选手应当提交如下材料。

1. 项目创意书（PDF版本，不少于500字）：包含赛题方向、项目背景、实务痛点、核心功能、应用价值、落地规划等。

2. 详细技术文档：技术路线说明、模型与框架选型、系统架构、数据集说明、安全与合规设计、局限性说明。交付文件：[Markdown 版](详细技术文档.md) · [Word 版](详细技术文档.docx)。

3. 功能演示视频：时长3-5分钟，MP4格式，分辨率不低于1080P（1920×1080），完整展示智能体核心操作与运行效果；可提供公开视频访问链接。

4. 作品原型/可访问演示入口：可部署网页、本地可运行程序、镜像包等，若为线上服务需要提供测试账号和密码。
