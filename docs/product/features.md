# 知识产权办案助理 · 产品需求

面向知识产权律师的私人 AI 助理，专注于侵权案件的办案辅助。

## 核心功能

### 1. 证据分析
- 针对用户「已提供」的证据，分析证明力、与待证事实的关联性、证明缺口与薄弱环节
- 给出质证意见与补强建议，不替用户凭空收集或编造未提供的证据
- 支持上传取证材料、合同、往来邮件进行要点提炼与比对

### 2. 辩论稿与法律文书撰写
- 草拟代理词、辩论意见、起诉状 / 答辩状要点、质证意见
- 生成赔偿计算说明（结合计算器工具，精确核算）
- 结构清晰、逻辑严密、用语符合法律文书规范

### 3. 法律法规与案例检索
- 检索法条、司法解释、指导性案例与生效裁判
- 联网搜索并标注来源：法条含制定机关与文号，案例含法院、案号、裁判要旨
- 严禁编造依据，无法核实的内容明确提示"需进一步核实"

### 4. 多轮对话记忆
- 完整保留上下文，连续沟通不跑题
- 可围绕同一案件逐步深化（先检索、再分析证据、最后起草辩论稿）

### 5. 历史会话管理
- 左侧会话列表，可新建 / 切换 / 删除
- 按案件维度组织对话，数据保存在本地浏览器

### 6. 文档分析
- 上传判决书、合同、取证材料（TXT / Markdown / CSV / 代码 / PDF）
- 助理基于文档内容作答、归纳与比对

### 7. 工具调用（实时可见）
- 计算器：赔偿数额、折扣、税费等精确计算
- 日期时间：期限、诉讼时效核算
- 联网搜索：法条与案例检索

## 设计风格
- 商务专业风：沉稳商务蓝主色，清晰留白与卡片化布局
- 对话式工作台：左侧会话列表 + 中间消息流 + 底部输入框
- 工具调用以可折叠卡片呈现，证据 / 辩论稿以 Markdown 表格与列表展示

## 技术说明
- 前端：React 19 + Vite + Tailwind + shadcn/ui，SSE 流式输出
- 后端：Express，封装 OpenAI 兼容接口，在 `/api/agent/chat` 以 SSE 暴露
- 模型接入：任意 OpenAI 兼容服务（默认 DeepSeek），配置于 `backend/.env`
- 无需数据库：会话存于浏览器本地
