# 知识产权办案助理 · 产品需求

面向知识产权律师的私人 AI 助理，专注于侵权案件的办案辅助。

## 核心功能

### 1. 证据分析
- 针对用户「已提供」的证据，分析证明力、与待证事实的关联性、证明缺口与薄弱环节
- 给出质证意见与补强建议，不替用户凭空收集或编造未提供的证据
- 支持上传取证材料、合同、往来邮件进行要点提炼与比对

### 2. 辩论稿与法律文书撰写
- 草拟代理词、辩论意见、起诉状 / 答辩状要点、质证意见
- 生成赔偿计算说明（结合计算器工具，精确核算）
- 结构清晰、逻辑严密、用语符合法律文书规范

### 3. 法律法规与案例检索
- 检索法条、司法解释、指导性案例与生效裁判
- 基于已提供知识库与材料整理并标注出处；不进行实时联网检索
- 严禁编造依据，无法核实的内容明确提示"需进一步核实"

### 4. 多轮对话记忆
- 完整保留上下文，连续沟通不跑题
- 可围绕同一案件逐步深化（先检索、再分析证据、最后起草辩论稿）

### 5. 历史会话管理
- 左侧会话列表，可新建 / 切换 / 删除
- 按案件维度组织对话，数据按登录账号保存在 CloudBase PG

### 6. 文档分析
- 上传判决书、合同、取证材料（TXT / Markdown / CSV / 代码 / PDF）
- 助理基于文档内容作答、归纳与比对

### 7. 工具调用（实时可见）
- 计算器：赔偿数额、折扣、税费等精确计算
- 日期时间：期限、诉讼时效核算
- 技能加载：根据任务按需加载内置工作规范，不提供网页搜索

### 8. Skills
- 检索法条、检索案例、知产新闻、合同起草与审核均以独立 `SKILL.md` 维护
- 通过 Skills 面板、`/skills`、`$技能名` 选择，或由模型依据描述调用 `load_skill`
- 初始只提供技能描述，执行时加载完整规范，会话记录实际使用的技能
- 首页不再展示技能快捷卡片，通过输入框 Skills 按钮选择；选中立即准备并可预览系统提示词，保留用户输入
- 参考规范与交付模板分为激活加载和按需读取，版本变化时提示重新加载
- 新闻需要提供正文；法条版本、案例效力等无法核实时明确标注
- 用户隔离与模型外发授权适用于所有技能

### 9. 模型选择
- 对话输入框底部的模型按钮向上展开菜单，沿用现有模型并按平台分组
- 已选择的型号与图片理解能力单独标注，缺少平台 API Key 的型号置灰
- 配置平台 Key 即可选择对应型号，账号的模型外发授权仍需开启
- 列表加载失败可重试；生成或识别卷宗时禁止切换，不自动跨模型回退

## 设计风格
- 商务专业风：沉稳商务蓝主色，清晰留白与卡片化布局
- 对话式工作台：左侧会话列表 + 中间消息流 + 底部输入框
- 工具调用以可折叠卡片呈现，证据 / 辩论稿以 Markdown 表格与列表展示

## 技术说明
- 前端：React 19 + Vite + Tailwind + shadcn/ui，SSE 流式输出
- 后端：Express，封装 OpenAI 兼容接口，在 `/api/agent/chat` 以 SSE 暴露
- 模型接入：任意 OpenAI 兼容服务（默认 DeepSeek），配置于 `backend/.env`
- 数据持久化：CloudBase PG 与私有文件存储，部署步骤见 `docs/cloudbase.md`
