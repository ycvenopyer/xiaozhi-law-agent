# 小知知识产权合规助理功能说明

小知帮助研发和法务团队在立项、发布和合作前核对知识产权风险。首页四个示例对应下列业务，点击示例可填入聊天草稿，点击输入框上方的业务按钮可进入结构化表单。

## 四个主要功能

| 入口 | 操作和结果 |
| --- | --- |
| 检索对比 | 在本账号知识库查找材料，输入两方标识或作品进行要素对照。专利 FTO 在当前页面核对特征、编辑关键词、复制检索式，回填外部 CSV 并导出初筛报告。 |
| 侵权识别 | 填写权利基础、行为、时间、关系、警告与已采取措施。商标、著作权和商业秘密按各自要件评估，专利进入检索初筛。 |
| 合规提示 | 按阶段勾选研发清单，生成合规提示初稿并存入对话，可导出 Markdown 或 Word。也可分析开源许可证、职务成果、保密、竞业、保护策略和合同条款。 |
| 知产文书 | 填写交易事实，生成保密协议、知识产权许可合同、职务发明约定或竞业限制初稿，支持 Markdown 和 Word 导出。 |

生成报告时，模型使用脱敏事实与已启用的参考资料。正文边生成边显示，完整报告经结构、风险等级和引文核对后写入本账号历史。长报告分段生成，或在单次请求结束前保存已有正文。点击「继续生成」可从保存位置续写同一条回复。权威来源页提供法规及审查指南的官方查阅入口。公共条文按施行区间筛选，未核对的旧内置参考资料不参与引用。

生成回答或文书时，可切换对话、浏览项目或启动另一条对话。工作台和合同面板可点「转到后台」，侧栏显示对应对话的生成状态，停止按钮只中止当前对话。生成依赖当前浏览器标签页，刷新或关闭标签页会断开请求。

专利 CSV 与复核备注在页面内存中处理。映射模板仅在点击保存后写入账号设置。关闭页面前可导出 Markdown 或 DOCX，其中包含来源、字段映射、候选与复核记录。

## 对话与工作区

### 多轮对话记忆

- 保留对话历史。发送时使用本轮对话历史，消息数和请求体受接口限制
- 可围绕同一案件逐步深化（先核对授权范围，再列出所需条款，最后起草许可合同）

### 历史会话管理

- 侧边栏分为置顶、项目与普通对话，支持展开/折叠；窄屏使用抽屉导航
- 对话菜单支持重命名、置顶/取消置顶、删除、移至项目或移回普通对话
- 侧边栏顶部可按标题或消息内容搜索本账号的普通、置顶和项目对话
- 长对话可滚动到最后一条消息，向上翻阅时可用「跳到底部」返回
- 可创建、重命名和删除项目，在项目页查看已有对话或新建项目对话；删除项目保留对话
- 名称、置顶、项目归属及当前视图按登录账号保存到 CloudBase PG，刷新可恢复
- 已手动命名的对话不会被第一条消息覆盖标题，空对话也可整理和保存

### 文档分析

- 用回形针选择文件、把文件拖到对话输入框，或在输入框内按 Ctrl+V 粘贴。支持 PDF、DOC、DOCX、TXT、Markdown、CSV 和 PNG、JPEG、WebP，每件最多 4 MiB，可一次添加多件。普通文字照常粘贴。
- 来源应用须向浏览器提供实际文件；微信消息卡片若只传递路径或链接，可先另存文件再拖入。附件出现后即可随消息发送，发送前可撤下。已保存的原件可从设置下载。 [浏览器拖放规范](https://html.spec.whatwg.org/multipage/dnd.html#dom-datatransfer-files) · [剪贴板事件规范](https://www.w3.org/TR/clipboard-apis/#clipboardevent-interfaces)
- 助理基于提取文本作答、归纳与比对。图片需要支持视觉输入的模型

### 工具调用（实时可见）

- 计算器：赔偿数额、折扣、税费等精确计算
- 日期时间：期限、诉讼时效核算
- 联网搜索：配置 Tavily Key 后，支持工具调用的模型可以检索公开网页并引用来源

### 检索、合同与知产新闻入口

- 对话输入框提供检索对比、侵权识别、合规提示、知产文书和合同起草（审核）按钮
- 「上传文件填表」支持选择一份或多份 PDF、Word、TXT、Markdown 或图片，再选择四个知产业务之一。系统将识别结果填入可编辑表单，覆盖该业务的当前草稿。单文件最多 4 MiB，合计最多 4 万字和 8 张图片或扫描页。图片和扫描页需选择视觉模型，识别前需开启模型外发授权。
- 合同面板支持技术开发、许可、转让、保密和竞业限制，区分起草与审核，可粘贴或上传材料
- 事务台位于右上角知识库旁。文件起草包含邮件、合规与风控、争议解决。生成稿保存为对话，可导出 Markdown 或 Word
- 文档解析从文字版 PDF、Word、TXT、Markdown 或粘贴文本提取当事人、案号、要旨、金额、引用法条及日期，附原文片段。扫描版 PDF 请先 OCR
- 专业翻译支持简体中文、英语、日语、韩语、法语、德语和西班牙语，使用内置知产术语并保留条款编号。长译文可从保存的段落继续翻译，译文保存为云端对话
- 新闻使用「设置 → 联网搜索」填写的 Tavily API Key，按北京时间筛选当天的结果并提供原文链接。搜索请求只发送预置的公开检索词

### 模型选择

- 对话输入框底部的模型按钮向上展开菜单，提供智谱内置模型和用户已添加的自定义模型
- 已选择的型号与图片理解能力单独标注，缺少 API Key 的型号置灰
- 智谱内置模型使用后端的 `ZHIPU_API_KEY`，发送对话需开启账号的模型外发授权
- 模型列表加载失败可重试。可以在其他对话里为新任务选择模型，正在生成的请求沿用启动时选择的模型
- 自定义模型按供应商和系列呈现正式名称及 API 模型 ID，也可手动填写 ID。支持设置 Base URL、API Key、显示名称、能力选项和连通测试。Key 随当前标签页会话保存，退出登录时清除

### 账号、隐私与设置

- 桌面端左侧展示品牌，右侧可切换「验证码登录」和「密码登录」，手机端上下排列。登录框下方可打开注册弹窗。填写账号名称、邮箱和密码，验证邮箱并完成注册后回到登录。已有账号在「设置 → 登录账号」可改名、换绑邮箱或用已绑定邮箱的验证码修改密码
- 登录后，左下角优先显示已设置的用户名，未设置时显示邮箱。账号菜单提供同步状态、设置、帮助和退出登录
- 设置包含「登录账号」「账号与隐私」「界面外观」「联网搜索」和「文件下载」。模型处理授权位于「账号与隐私」，原件在「文件下载」中通过私有存储校验下载
- 首次进入时，引导用户选择模型处理授权并配置可选的 Tavily Key。第三方模型处理默认关闭

### 法规版本与核对方式

知识库的「权威来源」列出升级清单中的法律、行政法规、司法解释和指南。CloudBase 的 158 条公共资料包括 144 条分版本法规原文、6 条案例和 8 条参考资料。用户新增的法条与案例归本账号，可自行编辑和删除。公共原文由管理员维护。两部审查指南提供官方原文与修订入口。商标法按北京时间在 2027-01-01 切换版本。历史行为的适用规则需结合发生时间复核。 [国家知识产权局商标法修订文本](https://www.cnipa.gov.cn/art/2026/6/26/art_3686_206940.html)

知产惩罚性赔偿使用法释〔2026〕7号，知产刑事司法解释使用法释〔2025〕5号，专利优先审查使用局令第85号。修订前后版本在清单中出现差异时，核对官方文本的施行和废止条款。 [最高法惩罚性赔偿解释](https://www.court.gov.cn/zixun/xiangqing/497911.html) · [两高知识产权刑事解释](https://ipc.court.gov.cn/zh-cn/news/view-4225.html) · [专利优先审查管理办法](https://www.cnipa.gov.cn/art/2026/7/30/art_74_207457.html)
