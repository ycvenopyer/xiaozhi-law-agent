# 知识产权办案助理 · 功能说明

面向知识产权律师的私人 AI 助理，专注于侵权案件的办案辅助。

## 核心功能

### 1. 证据分析
- 针对用户「已提供」的证据，分析证明力、与待证事实的关联性、证明缺口与薄弱环节
- 给出质证意见与补强建议，不替用户凭空收集或编造未提供的证据
- 支持上传取证材料、合同、往来邮件进行要点提炼与比对

### 2. 辩论稿与法律文书撰写
- 草拟代理词、辩论意见、起诉状 / 答辩状要点、质证意见
- 生成赔偿计算说明（结合计算器工具，精确核算）
- 结构清晰、逻辑严密、用语符合法律文书规范

### 3. 法律法规与案例检索
- 检索法条、司法解释、指导性案例与生效裁判
- 基于已提供知识库与材料整理并标注出处；不进行实时联网检索
- 严禁编造依据，无法核实的内容明确提示"需进一步核实"

### 4. 多轮对话记忆
- 保留对话历史。发送时使用本轮对话历史，消息数和请求体受接口限制
- 可围绕同一案件逐步深化（先检索、再分析证据、最后起草辩论稿）

### 5. 历史会话管理
- 侧边栏分为置顶、项目与普通对话，支持展开/折叠；窄屏使用抽屉导航
- 对话菜单支持重命名、置顶/取消置顶、删除、移至项目或移回普通对话
- 侧边栏顶部可按标题或消息内容搜索本账号的普通、置顶和项目对话
- 长对话可滚动到最后一条消息，向上翻阅时可用「跳到底部」返回
- 可创建、重命名和删除项目，在项目页查看已有对话或新建项目对话；删除项目保留对话
- 名称、置顶、项目归属及当前视图按登录账号保存到 CloudBase PG，刷新可恢复
- 已手动命名的对话不会被第一条消息覆盖标题，空对话也可整理和保存

### 6. 文档分析
- 上传判决书、合同、取证材料，常用格式包括 TXT、Markdown、PDF、DOCX 和图片
- 助理基于提取文本作答、归纳与比对。图片需要支持视觉输入的模型

### 7. 工具调用（实时可见）
- 计算器：赔偿数额、折扣、税费等精确计算
- 日期时间：期限、诉讼时效核算

### 8. 检索、合同与知产新闻入口
- 对话输入框提供检索法条、检索案例和合同起草（审核）按钮
- 法条可填写法典名称、条文序号和关键词；案例可按案由、类型、程序、法院层级和年份筛选
- 快速模式简要列出相关材料，深度模式分析匹配条件和待核实信息；均不进行网页搜索
- 合同面板支持技术开发、许可、转让、保密和竞业限制，区分起草与审核，可粘贴或上传材料
- 事务台位于右上角知识库旁，提供今日知产新闻和文件起草。新闻使用「设置 → 联网搜索」填写的 Tavily API Key，按北京时间筛选当天的搜索结果并提供原文链接
- 文件起草结果保存为云端对话。新闻结果在事务台展示，搜索请求只发送预置的公开检索词

### 9. 模型选择
- 对话输入框底部的模型按钮向上展开菜单，提供智谱内置模型和用户已添加的自定义模型
- 已选择的型号与图片理解能力单独标注，缺少 API Key 的型号置灰
- 智谱内置模型使用后端的 `ZHIPU_API_KEY`，发送对话需开启账号的模型外发授权
- 模型列表加载失败可重试。生成中禁用模型切换，错误发生后不会自动跨模型回退
- 自定义模型支持厂商预设、Base URL、API Key、模型 ID、显示名称、能力选项、连通测试及编辑删除。Key 随当前标签页会话保存，退出登录时清除

### 10. 账号、隐私与设置

- 桌面端登录页采用左侧品牌展示、右侧邮箱验证码表单，手机端上下排列
- 登录后，左下角账号菜单提供同步状态、设置、帮助和退出登录
- 设置包含界面外观、第三方模型处理授权、旧资料导入和文件原件下载
- 第三方模型处理默认关闭。旧资料需要用户确认后导入
- 卷宗、期限台账和利益冲突入口已下线。相关旧记录仍可导入并按账号隔离

## 设计风格
- 商务专业风：沉稳商务蓝主色，清晰留白与卡片化布局
- 对话式工作台：左侧会话列表 + 中间消息流 + 底部输入框
- 工具调用以可折叠卡片呈现，证据 / 辩论稿以 Markdown 表格与列表展示

## 技术说明
- 前端：React 19 + Vite + Tailwind + shadcn/ui，SSE 流式输出
- 后端：Express，封装 OpenAI 兼容接口，在 `/api/agent/chat` 以 SSE 暴露
- 模型接入：智谱通过后端环境变量启用，自定义模型由用户从输入框配置 OpenAI 兼容接口
- 数据持久化：CloudBase PG 与私有文件存储，见 [CloudBase 配置](cloudbase.md)
