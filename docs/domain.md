# EdgeOne Pages 自定义域名配置指南

本指南适用于已经在腾讯云 EdgeOne Pages 部署成功，希望通过固定域名长期访问项目的情况。

核实日期：2026 年 11 月 6 日。控制台界面、套餐和备案政策可能调整，实际操作以腾讯云最新提示为准。

## 1. 是否需要购买域名和服务器

EdgeOne Pages 的预览链接有效期为 3 小时，这不代表项目只部署了 3 小时。绑定自定义域名后，可以通过固定地址访问网站，不需要反复生成预览链接。

- **域名**：需要拥有一个域名。如果已经有域名，可以直接使用其子域名，例如 `law.example.com`，无需再次购买。
- **服务器**：网站继续托管在 EdgeOne Pages，通常不需要另外租服务器。但首次办理大陆 ICP 备案、部署独立后端时，可能涉及额外云资源，详见后文。
- **腾讯云支持情况**：可以在腾讯云完成域名注册、DNSPod 解析、Pages 绑定和 HTTPS 配置。

域名需要按年续费。购买时同时关注首年价格和续费价格，并设置到期提醒或自动续费。

## 2. 选择加速区域

| 加速区域 | 域名要求 | 适合场景 |
| --- | --- | --- |
| 全球可用区（不含中国大陆） | 无需 ICP 备案 | 希望尽快上线、比赛展示 |
| 中国大陆可用区，或全球可用区（含中国大陆） | 域名必须完成 ICP 备案 | 主要面向国内用户、长期运营 |

选择境外节点不代表国内用户不能访问自定义域名，但实际速度和稳定性需要测试。平台默认域名与自定义域名的访问规则有所不同，不要仅凭默认预览地址的访问结果判断自定义域名是否可用。

如果目前主要用于比赛展示，可以先选择“全球可用区（不含中国大陆）”；如果准备长期面向国内用户运营，再规划备案和大陆节点。

## 3. 注册域名

1. 登录腾讯云，搜索“域名注册”。
2. 查询希望使用的域名，确认可注册。
3. 核对首年价格、续费价格和注册年限后购买。
4. 按控制台提示完成域名实名认证。

**域名实名认证与 ICP 备案是两件事，完成实名认证不等于完成备案。**

如果已有域名，可以跳过购买，使用例如 `law.example.com` 的子域名。后续 DNS 配置需要在该域名实际使用的 DNS 服务商处完成；域名在腾讯云购买，并不意味着它一定使用 DNSPod 解析。

## 4. 确认 Pages 加速区域

1. 进入腾讯云控制台 → EdgeOne → Pages。
2. 打开已部署的项目，进入项目设置。
3. 查看项目的加速区域。
4. 如果域名尚未备案，使用“全球可用区（不含中国大陆）”。如果控制台不允许直接修改，按页面提示处理。

如果计划使用包含中国大陆节点的区域，应先完成 ICP 备案，再绑定域名。

## 5. 添加自定义域名

以下以 `law.example.com` 为例，操作时替换为自己的真实域名。

1. 在 Pages 项目中进入“域名管理”（部分界面位于项目设置内）。
2. 点击“添加自定义域名”。
3. 输入 `law.example.com`，不需要添加 `https://` 或路径。
4. 如果页面要求选择关联环境，正式网站选择“生产环境”，并确保该环境已有成功的部署。
5. 按弹窗指引完成域名所有权验证。如果要求添加 TXT 等记录，保留页面提供的主机记录、类型和记录值。
6. 复制 Pages 分配的 CNAME 地址，供下一步配置解析使用。

## 6. 在 DNSPod 配置解析

如果域名使用腾讯云 DNSPod 解析：

1. 打开腾讯云“云解析 DNS / DNSPod”控制台。
2. 找到对应根域名，例如 `example.com`。
3. 点击“解析”→“添加记录”。
4. 按 Pages 提供的信息填写 CNAME：

| 字段 | 填写内容 |
| --- | --- |
| 主机记录 | `law`，对应 `law.example.com` |
| 记录类型 | `CNAME` |
| 线路 | 默认 |
| 记录值 | Pages 提供的 CNAME 地址 |
| TTL | 保持默认 |

其他域名形式对应的主机记录：

| 希望访问的域名 | 主机记录 |
| --- | --- |
| `law.example.com` | `law` |
| `www.example.com` | `www` |
| `example.com` | `@` |

**CNAME 记录值必须复制 Pages 提供的目标地址，不要填写带临时验证参数的预览链接，也不要添加 `https://` 或 URL 路径。**

如果 Pages 还要求添加 TXT 验证记录，按照页面提供的字段另行添加。若同一主机记录已有冲突解析，先确认原记录是否仍被其他业务使用，再调整。

域名使用其他 DNS 服务商时，在该服务商的解析控制台执行相同操作，无需为了绑定 Pages 而迁移域名注册商。

## 7. 验证域名与 HTTPS

1. 返回 Pages 的域名管理页面，点击“验证”，或等待平台自动检测。
2. 等待 DNS 解析生效。通常几分钟即可，但可能更久，官方提示最长可能达到 48 小时。
3. 等待域名状态正常，以及 HTTPS 证书签发、部署完成。Pages 支持自动配置免费 HTTPS 证书，按页面提示启用即可。
4. 使用 `https://law.example.com` 访问网站。
5. 检查首页、页面刷新、登录、问答及接口请求是否正常，并在电脑和手机网络下分别测试。

绑定成功后，对外分享自定义域名即可，无需反复生成 3 小时预览链接。

## 8. 哪些情况可能需要服务器

### 首次办理大陆 ICP 备案

腾讯云当前备案流程要求符合条件的境内云资源，或有效备案授权码，因此首次通过腾讯云办理备案时，可能需要额外购买符合条件的云资源。

不要只为绑定域名就直接购买服务器。先确认使用区域、已有备案情况和腾讯云当前的备案资格要求，再决定需要购买什么资源。

### 独立后端或数据库仍在本地

绑定域名只解决网站访问入口。如果后端、数据库或 AI 接口仍依赖开发电脑上的服务，它们也需要部署到线上。

是否需要服务器取决于后端架构，也可以考虑平台函数、托管数据库等方式。绑定前端域名不会自动完成独立后端的部署。

## 9. 长期维护

- 按时续费域名，避免到期后网站无法访问。
- 关注 Pages 当前套餐、用量配额和平台政策，绑定域名不代表所有服务永久免费。
- 保持生产环境存在有效部署，发布后检查自定义域名访问情况。
- 维护后端服务、数据库和 AI 接口余额或配额。
- 如果使用大陆节点，保持备案信息有效，并按要求办理后续变更。
